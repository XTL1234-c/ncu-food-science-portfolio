## 🏫 关于南昌大学

> 南昌大学是国家"双一流"建设高校，办学历史可追溯至 1940 年创办的国立中正大学。
> 食品科学与工程学科依托 **食品科学与技术国家重点实验室**（南昌大学共建），
> 在粮油加工、畜产加工、果蔬加工与食品安全等领域具有鲜明特色。

本作品集用于存放本学期课程作业、实验报告与项目作品，**仅作学习交流使用**。
